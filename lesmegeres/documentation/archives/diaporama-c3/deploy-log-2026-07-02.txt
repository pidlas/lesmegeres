ANALYSE COMPLÉTÉE
=================

1. ✅ Diagnostic du problème
   - Identifié : Image c3 dimensions 1280×720 (16:9 exact)
   - Cause : background-position: 49.5% + background-size: cover
   - Effet : Clipping asymétrique laissant blanc à gauche/droite

2. ✅ Comparaison d'images
   - c1-c7 dimensions vérifiées
   - c3 est la SEULE avec ratio 16:9 exactement standardisé
   - Autres images ont dimensions irrégulières (pas affectées)

3. ✅ Analyse du JavaScript
   - app.js vérifié (gestion diaporama)
   - Aucune logique spécifique à c3 trouvée
   - Problème confirmé comme purement CSS

MODIFICATIONS APPLIQUÉES
=========================

Fichier : /var/www/public/css/style.css
───────────────────────────────────────

Changement 1 (ligne ~930) :
─────────────────────────
AVANT :
  .card[for="c3"] {
      background-image: ... ;
  }

APRÈS :
  .card[for="c3"] {
      background-image: ... ;
      background-position: center !important;
      background-size: cover !important;
  }

Changement 2 (ligne ~942) :
──────────────────────────
AVANT :
  .card[for="c3"],
  .card[for="c4"] {
      background-position: 49.5%;
      border-radius: 1rem;
  }

APRÈS :
  .card[for="c3"],
  .card[for="c4"] {
      background-position: center;
      border-radius: 1rem;
  }
